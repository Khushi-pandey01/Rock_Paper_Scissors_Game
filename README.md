# 🪨📄✂️ Rock Paper Scissors Game with Score Tracker

An interactive, terminal-based Rock Paper Scissors game built using Python. 
This application features an automated AI opponent, live score tracking, smart validation, and an interactive replay loop.

## 🚀 Features
* **Smart Input Validation:** Catches typos instantly and prompts the user without breaking the program.
* **Automatic Tie Replay:** Detects identical choices and automatically replays the round.
* **Live Scoreboard & Final Summary:** Tracks points dynamically and presents a clean **FINAL SCORE** layout showing the overall winner.
* **Smart Play-Again Loop:** Validates user response for replay, ensuring only `y` or `n` inputs are accepted.
* **Visual Enhancements:** Uses clean dividers, alignment, and modern emojis (👊, 📄, ✂️, 📊) for a better UI experience.

## 🛠️ Tech Stack
* **Language:** Python 3
* **Modules Used:** `random` (built-in)

## 💻 How to Run
1. Clone this repository or download the source code.
2. Open your terminal or VS Code.
3. Run the following command:
   ```bash
   python Rock_Paper_Scissors_Game.py
   ```
